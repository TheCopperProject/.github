## 📌 About The Project

Copper is born out of a passion for the simplicity and control of **C**, combined with the expressive power and modern abstractions of languages like **Haxe**.

While C offers unmatched low-level control, it lacks built-in complex data structures, object-oriented capabilities, and modern syntax features out of the box. On the other hand, higher-level languages often rely on heavy runtimes or Garbage Collectors (GC). 

**Copper aims to bridge this gap:** providing a powerful, low-level language with modern developer ergonomics—without sacrificing performance or forcing a GC upon you.

## ❓ FAQ

#### **Why create Copper?**
> *"I love C, but I also love Haxe."*
> 
> C is wonderfully simple, but that simplicity can sometimes feel limiting when you need classes, rich data structures, or expressive abstractions. Haxe provides those high-level features, but compiling to C++ via HxCPP still relies on a Garbage Collector. Copper is an attempt to create the ideal low-level language: native performance, zero-cost abstractions, and clean syntax.

#### **What is the ultimate goal of this project?**
> The vision is evolving as the project grows, but the core promise remains the same: **to build a well-designed, reliable, and enjoyable low-level programming language.**
